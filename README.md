    # Лапа помощи

Telegram-бот для помощи собакам приюта «Бирюлёво». Показывает актуальные нужды приюта, принимает заявки на передачу вещей и помогает волонтёрам управлять визитами.

## Возможности

- Просмотр списка нужд и информации о приюте.
- Запись на передачу нужной вещи с выбором даты и времени.
- Уведомления волонтёлам о новых заявках и посетителю об их подтверждении или отклонении.
- Отмена заявки посетителем.
- Обновление списка нужд и просмотр предстоящих заявок через панель волонтёра.

Для записи доступны дни со среды по воскресенье, начиная через два дня, с 10:00 до 16:00 по московскому времени. Пока по позиции есть предстоящая заявка, ожидающая ответа или подтверждённая, другие посетители не могут её выбрать.

## Запуск

Понадобятся Python 3.10 или новее и токен Telegram-бота, полученный через [@BotFather](https://t.me/BotFather).

1. Создайте и активируйте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

   В Windows команда активации: `.venv\Scripts\activate`.

2. Установите зависимости:

   ```bash
   python -m pip install .
   ```

3. Создайте в корне проекта файл `.env`:

   ```dotenv
   BOT_TOKEN=токен_бота
   STAFF_IDS=
   VOLUNTEER_CONTACT=@username
   BOT_DB=shelter.sqlite3
   ```

4. Запустите бота:

   ```bash
   python main.py
   ```

5. Каждый волонтёр должен открыть диалог с ботом, отправить `/start`, затем `/id`. Впишите полученные числовые ID через запятую в `STAFF_IDS` и перезапустите бота. После этого команда `/admin` откроет панель волонтёра.

В панели выберите «Обновить список нужд» и отправьте позиции сообщением, по одной на строку. Новый список полностью заменит текущий.

## Настройки

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота; обязателен для запуска | — |
| `STAFF_IDS` | Числовые Telegram ID волонтёров через запятую | Пусто |
| `VOLUNTEER_CONTACT` | Контакт, который показывается в разделе о приюте | Не показывается |
| `BOT_DB` | Путь к файлу базы SQLite | `shelter.sqlite3` |

Не публикуйте `.env` и токен бота. Если изменили настройки, перезапустите процесс.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Открыть главное меню |
| `/id` | Узнать свой Telegram ID |
| `/admin` | Открыть панель волонтёра; доступна ID из `STAFF_IDS` |

## Railway

1. Создайте сервис из репозитория проекта. Railway автоматически обнаружит `Dockerfile` в корне.
2. В настройках проекта создайте Volume, подключите его к сервису и укажите Mount Path `/data`.
3. В Variables сервиса добавьте `BOT_TOKEN`, `STAFF_IDS` и при необходимости `VOLUNTEER_CONTACT`. Укажите также `BOT_DB=/data/shelter.sqlite3`.
4. Разверните сервис и проверьте журнал. База создастся в томе при запуске и сохранится при следующих развёртываниях.

Используйте один экземпляр бота. Если раньше бот работал без тома, существующую базу нужно отдельно скопировать в том до запуска с новым путём; иначе создастся пустая база. Том не заменяет резервное копирование.

## Docker Compose

Создайте `.env`, как описано выше, затем запустите из корня проекта:

```bash
docker compose up -d --build
docker compose logs -f
```

База хранится в именованном томе Docker `bot_data`, отдельно от контейнера и образа. Для обновления выполните `docker compose up -d --build` снова: том сохранится. Не используйте `docker compose down -v`, если хотите сохранить данные: эта команда удаляет том.

Если база уже существует на хосте, перенесите её до первого запуска нового контейнера. Остановите старый экземпляр бота, затем выполните из корня проекта (подставьте путь к существующей базе):

```bash
docker compose create
docker compose run --rm --no-deps --entrypoint python \
  -v "$(pwd)/shelter.sqlite3:/migration/source.sqlite3:ro" bot \
  -c 'import os, shutil; dst="/data/shelter.sqlite3"; assert not os.path.exists(dst), "База в томе уже существует"; shutil.copyfile("/migration/source.sqlite3", dst)'
docker compose up -d
```

Команда откажется перезаписывать уже существующую базу в томе. Если прежний бот работает в другом контейнере или на другом сервере, сначала сохраните его базу на хост и подставьте путь к ней. Для переноса остановите бот, чтобы файл базы не изменялся во время копирования.

## Хранение данных

Нужды, заявки и время обновления списка хранятся в SQLite. База и таблицы создаются автоматически при запуске; для резервного копирования сохраняйте файл базы. Запускайте только один экземпляр бота с этим токеном. Для получения уведомлений волонтёр должен сначала начать диалог с ботом.
